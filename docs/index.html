Grab

A fast, native download manager for GNOME.

Get Grab GitHub

Features

⚡ Segmented downloads

Split files across multiple connections for maximum speed, with automatic resume and integrity checks.

🎬 Video extraction

Download videos via yt-dlp with format selection, subtitles, and metadata — right from the URL bar.

🧲 Torrents

Full torrent support with magnet links, file selection, and progress tracking.

🔴 Live capture

Record live streams as they happen, with clean staging and crash recovery.

🧩 Browser extension

Send downloads straight from Firefox, Chrome, or Brave with the companion extension.

🎨 Native GNOME

Built with GTK 4 and libadwaita. Follows GNOME HIG, supports dark mode, and feels at home on your desktop.
